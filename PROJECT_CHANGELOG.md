## Attendance DTR export wiring

- **Team Attendance DTR generation wired to backend:** `GET /attendance/reports/dtr-mock-sample` now accepts query parameters from Team Attendance DTR dialog (`mode`, `employee_id`/`unit_id`, `date_from`, `date_to`) via [DownloadTeamAttendanceDtrRequest](app/Http/Requests/DownloadTeamAttendanceDtrRequest.php) and [DownloadDtrMockExcelController](app/Http/Controllers/DownloadDtrMockExcelController.php). With explicit scope, export builds real sheets; without scope (`mode=sample`/no mode), it still downloads the mock sample.
- **Workbook support for unit mode:** added [TeamAttendanceDtrWorkbookExport](app/Exports/TeamAttendanceDtrWorkbookExport.php) (`WithMultipleSheets`) so one employee = one worksheet in unit exports.
- **Derivation service + fallbacks:** [TeamAttendanceDtrExportService](app/Services/TeamAttendanceDtrExportService.php) now composes DTR sheets from attendance days + segments, approved leave days, approved overtime, holidays, and work schedule template snapshots. Implemented fallback/precedence behavior used by Team dialog rules:
  - Holiday with no logs -> blank row; holiday with logs -> logs win.
  - Rest day with no logs -> `REST DAY`; rest day with logs -> logs rendered.
  - Missing non-holiday/non-rest-day logs -> `ABSENCE` band.
  - Remarks only set to `OT` (approved OT + logs) or `OL` (approved leave).
  - No assigned work schedule -> sheet still generated; schedule reference shows an explicit “no assigned schedule” note and schedule-derived totals are unavailable (`—`).
  - Unit/period metadata now uses the employee’s resolved assigned unit path (`Root - ... - Actual Unit`) and position falls back to primary, then first available.
- **Team Attendance dialog wiring:** [Attendance/Team.vue](resources/js/pages/Attendance/Team.vue) now sends DTR scope query parameters to the download route instead of always downloading the static sample, and updates dialog copy to reflect real export generation.
- **Tests:** added [TeamAttendanceDtrExportServiceTest.php](tests/Feature/TeamAttendanceDtrExportServiceTest.php) and kept existing export/download coverage in [DtrMockExportTest.php](tests/Unit/DtrMockExportTest.php) and [DownloadDtrMockSampleExcelTest.php](tests/Feature/DownloadDtrMockSampleExcelTest.php).
